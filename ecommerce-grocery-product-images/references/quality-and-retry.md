# 生成后质检与返工

## 每张图质检

**商品身份：** 是否还是实拍中的商品；品种、数量、核心结构和包装是否正确？

**多图参考与事实来源：** 核对实际调用，是否上传至少两张互补本品实拍，并明确主参考和各图职责？整体形态、颜色、材质和目标展示状态是否分别有实拍依据？只看过多张却仅上传一张不符合要求；外部案例或生成图不能充当本品结构依据。不同视角的特征提取不能变成不同商品状态的随意拼接。

**主体完整性与结构连续：** 逐个检查主商品的可见轮廓、两端、果身、内部组织和连接是否符合约定的完整、剥开或切分状态。重点查看果肉—果皮、果身—枝柄、叶片—叶柄及包装开口—主体的关系；无故缺半、截短、断接、融合、用果皮代替果肉或用其他商品补缺，直接不合格。对遮挡沿边界检查轮廓方向、前后顺序及剩余空间是否支持主体自然延续，不能只说“可能在后面”就放过明显缺失。合理遮挡、明确切分和有目的的局部取景不要求所有隐藏部分可见。

**实拍质感：** 是否保留该商品实际的光滑或粗糙、干湿状态、颜色层次和材料特征？是否把色斑、水痕或噪点画成凹凸、线网或组织？是否出现 AI 重绘、塑料感、实拍不支持的厚重蜡膜感、CG、过度磨皮、过锐或过饱和？天然蜡层、果粉与原有光泽不应被当作缺陷抹去。

**形态与细节强度对照：** 用相近的商品显示大小比较可靠实拍与输出，检查轮廓、长宽关系、曲率、棱面与首尾连接；不能只凭颜色和品类相同判为身份正确。切面若出现实拍没有的密集亮纹、颗粒、沟槽或明显增加的起伏，判为质感失败，不用“新鲜湿润”解释通过，也不以整张模糊掩盖。

**修整幅度：** 是否只改善明确指出的问题？是否把商品品质或状态美化到脱离实售？构图变化是否必要？

**较大损伤与小瑕疵：** 先按正常展示尺度判断，再对照记录的位置，检查突出的较大残缺、擦伤和伤斑是否自然修整，包含透明包装内可见的商品。不能仅因“原片也有”就通过，也不能放大寻找并清除所有小瑕疵。检查小斑点、轻微擦痕、自然色差、正常切口和完整干燥果端是否仍被保留；修得均匀无瑕同样不符合真实感要求。

**六图任务：** 当前图号承担的信息是否清晰？与整套其他图相比，商品状态、排布与取景是否有实际的信息差别？02 与 03、04 与 05 是否各自互补？商品是否始终是主体？

**构图决策与表现：** 是否有基于商品形态和本图任务的系统选型，而非直接套用场景？实际结果的主次、尺度、留白、裁切和支撑是否成立？不同产品是否仅替换了同一排布中的商品？以信息和可见美感判断，不要求每张都非对称、三层景深或完全相同的占比，也不把与计划的无害差异一律判成失败。

**01—03 商品构图：** 是否主动组织了商品的姿态、组合、切面方向、机位或留白？若三张只是同一原片的连续裁切、单个大圆贴满画面或同一排布越拍越近，属于构图任务未完成。近景、单件或居中本身可以成立，判断依据是信息与关系，不强制多件或添加装饰。

**04、05 产品关注度：** 场景是否主要由商品、容器、承载面和少量必要配件构成？椅子、办公室、房间或大量环境是否挤占画面，商品是否变成环境中的一个摆件？通常用局部布景就能表达的用途，不通过扩大空间补充。比较摆盘、台面、器皿、光色和机位的差异，不能只用不同房间证明两图有区别。

**细节图边界：** 02、03是否聚焦商品本体，并排除了砧板、餐具等生活工具？果肉或切块方向可以成立，生活器具误入仍属于图号功能不符；不能因器具本身比例、光线合理而通过此项。

**03 美感细节：** 是否以果肉、切面、切瓣、厚度或其他有效结构为主体，提供与 02 互补的信息？果皮、果柄、果肩色带或表皮纹理特写不符合本图方向。少量真实切面外皮边缘与弱化身份参照可以保留；不能通过加入工具、放大整果或加强纹理来制造细节。

**03 满铺组合：** 商品铺满画面本身不构成失败，也不要求大片背景留白。检查是否存在明确的细节主体，周围商品是否通过朝向、遮挡、自然明暗或景深形成陪衬；是否有依据的数量、可信承托和个体差异。满铺却没有主次、主体被遮住、复制同一纹样、凭空增量或靠过锐与伪纹理突出主体，判为不合格。边缘陪体的有目的裁切不等于无故缺失，仍按结构连续与遮挡依据检查。

**包装：** 材质、形态、Logo、品牌、文字、标签、配色和结构是否忠于实拍？褶皱修整是否仍符合材料特性？

**光影与物理：** 摄影模式是否正确？光源是否统一？商品是否有可信支撑、接触阴影和透视？

先按正常展示大小判断整体，再对照实拍适度放大关键区域；比较时让商品显示尺度接近。既不能只凭缩略图放过伪纹理，也不能用无限放大追求不存在的完美表面。整套再并看排布、色调与细节强度，单张好看不能代替整套分工。用户已认可的版本作为当前风格基准，后续保留未被要求修改的部分；商品身份、标签与物理结构问题仍应具体说明。

## 04、05场景图实际逻辑审核

按可见证据判断以下关系，不要求画面展示所有隐藏结构，也不为证明生活感额外添加水迹、工具或杂物。

| 检查项 | 判断依据与边界 |
| --- | --- |
| 光线方向 | 对照环境光源位置、商品主要受光面和主要投影方向，判断是否能由同一套主光、环境反射与补光解释。不同朝向切面的明暗不同、金属局部亮边或柔光下不明显的投影，本身不构成矛盾。 |
| 容器与商品比例 | 比较相近深度处的商品大小、容器开口与可见容量，检查能否容纳当前数量和摆放，是否挤穿边壁。考虑近大远小与裁切；无标尺时不虚构确定尺寸，也不预设所有商品都应采用同一容器比例。 |
| 重力与支撑 | 查看商品与台面、容器或相邻商品的接触、遮挡及接触阴影，检查明确的悬空、穿透或失稳。接触点被合理遮挡、摆放整齐或切块竖立，不能单独作为失败证据。 |
| 透视与遮挡 | 检查容器边缘、底面和台面的透视是否连贯，物体交界的前后顺序是否成立，餐具是否穿入容器或水果。不能直接用近景且部分出框的餐具推断商品尺度错误。 |
| 使用阶段 | 画面中的商品状态、工具位置及必要功能关系应支持所声称的阶段。例如正在沥水应有可信排水去向，沥干后整理可以放在台面；切配与装盘待食各自只需对应的必要器具。不能把合理的后续阶段误判为前一阶段缺少动作。 |

审核结果区分：**明确错误**须指出位置与证据并返工；**可疑但证据不足**记录判断边界，不强制修改；**可选自然化**属于摆拍程度或生活感优化，不等同物理错误。未发现明显矛盾且用途成立时可以通过，不为凑问题或追求绝对自然反复生成。

## 直接不合格

商品身份或核心结构改变、明显 AI 纹理、严重变形、包装文字错误、商品数量异常、物理关系错误、光源严重冲突或过度美化，均判定为不合格。发现问题时先指出具体失败项，不把失败图作为已完成交付。

主体无故缺失、结构中断或材料错接，不能因画面好看而通过。例如宣称完整剥开的香蕉只留下前半段果肉，后半段没有可信的延续或切分依据，属于结构失败，不能归为合理美化。

02、03出现作为道具的生活工具，判为细节图功能不符。保留有效的商品细节方向，移除器具并恢复中性承托环境；不必为此改成另一种商品细节或生活场景。

03 仍以果皮、果柄、果肩色带或表皮纹理为主题，判为方向不符；回到有实拍依据的美感细节方案，不把增强锐度或轻微换角当作修正。

已确认的较大展示损伤仍被保留，属于必要修整未完成。应局部修复或改选更完整参考，再检查材质、数量和结构，以及周围小瑕疵是否仍自然保留。既不遗漏较大缺陷，也不将细小不完美全部抹掉。

## 返工策略

- 默认执行“生成 → 审核 → 针对明确失败项调整 → 重新生成 → 复查”的自动连续返工。首次失败须指出位置与证据，只调整造成失败的参考、方案或 Prompt 部分，并检查已认可内容是否漂移；合格即停止，不因可选优化或证据不足的猜测继续生成。
- 自动返工仍遵守参考输入和修整边界。反复加工不合格生成图不能代替重选原始实拍；用户要求仅用实拍时，实际上传输入不得包含生成图。用户补充反馈时并入当前任务，保留未要求修改的已认可内容。
- 同一问题连续两次仍失败时，下一次生成前先改变方案或参考选择，不只继续叠加禁词。伪纹理应检查参考材质、放大程度、水痕和细节强化要求；结构冲突应改选相同切法或视角的参考；排布重复应回到整套方案；包装信息漂移应加强原片保留；支撑错误或场景混乱再简化堆叠与道具。每次返工须有明确的问题、对应调整和复查目标。
- 若失败来自构图、主体尺度或排布，回到[前置构图决策](composition-planner.md)检查选型与支撑。内部没有合适方案或构图连续失败时再检索外部摄影，提取关系后重新设计当前商品；外部图不替代实拍材质和结构依据。
- 简化时保留本图的核心购买信息。若任务就是展示内部结构，不应直接取消切面来规避失败；可改用更可靠的切面实拍、景别或更保守的编辑方案。
- 单张最多生成五次，包含首版和全部自动返工；换参考、方案或编辑方式不能重置当前任务计数。五次仍不合格时标记并告知“暂不生成”，不得把失败图称为成品。整套任务继续下一图，单张任务停止并报告。用户明确要求停止时立即停止。
- 每次返工仍须使用四段 Prompt，并在下一次生成前重新检查商品事实与失败约束。

## 最终复查与交付

完成单图检查后按以下顺序复查；构图美观不能抵消商品事实错误：

1. 核对实际输入：至少两张互补本品实拍、主参考、各图职责与实际 Prompt 一致；外部灵感另记。检查第四段实际包含通用 Avoid 与本图关键约束。
2. 逐个追踪主体：展示状态、数量、完整轮廓、两端和部件连接正确；合理遮挡有可见依据，无故缺失、融合或截短直接判不合格。
3. 同等显示尺度比较：形态、比例、颜色、材质和细节强度忠于实拍；不出现强化亮纹、颗粒、深沟槽或生硬组织，不以模糊遮盖。
4. 检查修整：大缺陷已自然处理，小斑点、轻微擦痕、色差和个体差异保留；新鲜度改善不重塑形态或改变实售状态。
5. 检查图号与构图：01—03 有具体商品关系、角度和主次，背景留白按方案决定；02、03 无生活器具，03 聚焦美感细节，选择满铺时仍有清楚主体和可信结构；04、05 聚焦商品和局部布景；06 包装保真。整套功能、排布、色调和细节强度互补一致。
6. 检查光影与物理：支撑、接触阴影、容器容量、比例、透视、遮挡及光源成立；不把证据不足的猜测当作错误。
7. 保存真实调用和审核结论：明确通过项、具体不合格项与输出对应关系；明确不合格按返工策略自动处理，合格即交付，达到次数上限如实报告，不把未合格图称为终稿。

## 实际调用记录

生成前保存唯一文字构图方案、系统选型依据、将要发送的完整 Prompt 与有序参考输入；生成后关联图号、尝试次数、工具返回的文件或标识、采用状态和具体问题。局部返工也计入当前单张任务的尝试次数，并标明编辑底图与商品实拍，保留版本关系。

外部灵感另记作品链接、实际观察的构图关系及应用方式；没有检索时注明内部系统或沿用原构图。灵感网页、查看过的图片和真正上传的参考图分别标记，不能把“浏览过”写成“已作为生图输入”，也不能把外部参考的商品事实混入当前商品实拍。

用户索要实际提示词时，直接提供真实调用记录。若另行整理了更易复用的提示词，明确标为整理版。某一轮同时改了参考、构图、语言或多项描述时，只能确认它们共同伴随了结果变化，不能宣称其中某个词或某种语言已被证明更有效。
