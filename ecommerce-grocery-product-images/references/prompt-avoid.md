# 生图通用 Avoid

每张实际 Prompt 的第四段包含以下通用约束，再追加本图最关键的一两项风险及输出规格。前面的正向方案仍须说明商品状态、完整结构、参考职责和具体摄影关系；Avoid 不能代替有依据的设计。

## 通用原文

```text
Avoid：脱离本品实拍重塑品种、外形、比例、颜色或内部组织；主体无故缺失、截短、断接、融合或部件错位，以遮挡掩盖缺失、用另一种材料或其他商品替代缺失部分；擅自增减商品、复制相同个体或纹样；过度锐化、密集亮纹、夸张颗粒与沟槽、塑料或CG质感、磨成均匀无瑕；悬空、穿透、失稳、比例透视错误或光影冲突；无关道具和大范围环境抢占主体；篡改包装结构、标签文字或Logo，新增水印和文字。
```

## 按当前图补充

- **有剥开、切分或连接结构：** 按已确定的状态写明完整部件与连接。例如“避免完整剥开的果肉只剩半段，余下部分无故消失；避免果皮与果肉错接”。不把该例机械套用于其他商品。
- **02、03：** 避免生活器具；03 另避免果皮、果柄或表皮纹理成为主题。
- **04、05：** 避免为交代生活感扩大到椅子、办公室或整间房；避免容器与商品不相容、实际承托不成立。
- **06：** 避免改变实际包装版本、件数及软硬材质特性；不可猜写看不清的文字。

约束针对可见的事实错误；允许有依据的切分、合理遮挡、有目的的裁切、正常天然瑕疵和商品本身的粗糙材质。不将所有深色部位、自然湿润反光或细节都列为错误，不追加无关禁词清单。
