# 前置构图决策

在每张图的最终 Prompt 前确定一个可执行的构图。商品事实、真实性与修整边界、六图任务和用户本次要求优先于本模块。构图系统是筛选摄影关系的工具，不是固定场景或要求每个商品套用的模板。

## 决策顺序

商品形态与本图信息 → 内部构图系统选择 → 没有合适方案时外部检索 → 抽取构图关系 → 重新设计当前商品方案 → 检查数量、支撑和整套差异 → 输出唯一文字方案。

先检查已有实拍或用户认可的构图是否满足任务。满足时保留有效关系，并说明对应系统与依据；局部新鲜度、颜色或缺陷返工沿用已认可方案。用户要求重新构图、现有排布失败或功能重复时，再执行完整筛选。不能为增加变化而改动用户已限定的果柄形态、切法或摆放。

对新套图的 01—03，“能看清商品”不足以证明原构图合适。先设计商品组合、切面方向、姿态、机位和留白；不能默认照原片摆放再连续裁切放大。单件商品不强制增加陪体，近景本身也不等于失败，但取景应有信息目的，不能只剩占满画面的表面。

## 1. 判断商品形态与图片任务

读取完整品名、实拍及本次要求，确定：

- 图号、本张购买问题、必须看清的信息，以及与其他图的差别。
- 商品外形、真实比例、数量依据、天然朝向、可展示状态；是否有可靠的切开、拆开或内部结构实拍。
- 至少两张互补本品实拍实际输入的职责：主参考提供完整身份和展示状态，其他视角补充材质、内部组织、连接或包装；当前照片中需要改善的摆放与裁切。
- 用户要求保留的内容、允许的修整范围，以及当前构图需要解决的具体问题。

按画面中占主导的形态选型；同一商品可以在不同图中属于不同形态，例如整串香蕉强调簇状关系，单根或切段强调长轴。品名不能替代实拍事实，不从模糊区域补出结构。

| 主要形态 | 选择方向 | 主要风险 |
| --- | --- | --- |
| 圆形、椭圆形单体 | 单主体留白、双件错位、整体与切面、局部与整体参照 | 单个大圆贴满画面；多个商品如复制品 |
| 长条、弯曲单体 | 对角动势、自然轴线、平行错位或前后交错 | 首尾不清、强行拉直、机械等距排列 |
| 叶菜、松散结构 | 沿自然展开方向组织主次、整体与局部 | 绝对对称、凭空增叶、叶层穿插 |
| 成串、成簇 | 保留连接结构，组织疏密与景深 | 断开天然连接、无支撑堆叠 |
| 小颗粒、多数量 | 松散三角、自然聚集与少量分离 | 网格、相同纹样与朝向重复 |
| 袋、盒、瓶等包装 | 完整主包装、自然转角、组合装错位 | 结构改变、文字遮挡、软包硬化 |

## 2. 筛选内部构图系统

先排除不符合本图任务、数量依据、展示状态或支撑关系的系统，再比较剩余系统的识别度、信息表达、视觉主次、留白与整套差异。选一个主系统；必要时借用一种辅助关系，不混合多个完整方案。若无明确优选，可比较两种关系并记录选定理由，最终只保留一种。

| 构图系统 | 适用条件 | 需要决定的摄影关系 |
| --- | --- | --- |
| 单主体留白 | 一个完整主体已能完成任务，常用于 01、06 | 主体位置、完整轮廓、留白方向；允许自然居中 |
| 双件错位 | 已有两件商品或两个真实组成部分 | 一个主锚点，另一个补充信息；前后与朝向区别 |
| 三角节奏 | 已有三件或多个小型商品 | 松散稳定的视觉重心与主次，不强求几何三角 |
| 整体与切面 | 内部品质有价值且实拍支持切法，常用于 02 | 整体识别与切面信息的权重、前后和承托 |
| 主体与自身陪体 | 已有切瓣、切段或其他真实组成部分可补充信息 | 陪体承担何种信息、位置与较低视觉权重 |
| 局部与整体参照 | 局部需要身份线索，且数量依据允许 | 有效细节为锚点，整体弱化辅助；03 不选果皮主题 |
| 对角动势 | 长条、切段或多件天然方向明确 | 主方向、错位间距、自然曲率与稳定承托 |
| 自然聚散 | 小果、颗粒或松散商品 | 主聚集区、疏密和自然个体差异 |
| 商品满铺与细节主体 | 多件、切块或自然组织有依据，适合 03 | 有效切面、剥好部分或其他细节为视觉锚点，周围同商品形成陪衬；决定层次、朝向、边缘裁切和承托，不强制背景留白 |
| 前景、主体与背景层级 | 商品组合或局部布景能说明本图信息 | 清晰商品、低权重陪体和必要背景；不强制三层或宽空间 |
| 承载面上的应用 | 04、05 的食用、整理或准备阶段 | 商品与台面、必要容器或器具的实际功能关系 |

系统里的双件、三角、陪体等名称不构成新增商品授权。数量按商品主参考和用户已授权的展示方式确定；数量不足时换系统。切分后记录整件与各部分的关系，不把一个商品的切片画成额外完整商品，也不改变实际包装件数。

为 03 筛选满铺方案时，读取[03 布局参考](composition-03-layouts.md)并查看相关图片。参考只提供“同商品聚集形成画面、有效细节突出”的关系，当前商品结构、材质和实际输入仍以本品多张实拍为准。

## 3. 没有合适方案时检索外部灵感

触发条件：内部系统无法兼顾本图信息与美感、特殊形态缺少可信排布、细节和身份关系无法处理，或构图连续失败。内部已有适用方案时不强制检索；用户明确要求检索时按要求执行。

按目的选择检索入口，无须每次遍历全部网站：

- **ZCOOL / 站酷**：商业产品、食品、静物摄影及系列作品。检索“完整品名 + 产品摄影 / 食品摄影 / 静物摄影”。
- **VCG / 视觉中国**：同类商品商业实拍的切法、数量关系、视角与取景。检索“完整品名 + 静物 / 切面 / 产品摄影”，可补充英文品名。
- **58pic / 千图**：商品组合、主次、留白及电商展示关系。检索“完整品名 + 商品摄影 / 商品组合”。

先找同类商品；不足时扩展到相近形态和同一使用阶段。查看少量与本图有关的作品，优先实拍中结构可信的画面，不能仅凭标题或搜索摘要判断构图。记录实际查看的作品链接与可见关系，不虚构检索结果。网站不可访问时尝试其他入口；仍无可查看图片时记录限制，回到有实拍依据的简洁构图，不猜测外部作品。

外部作品用于构图灵感；商品的品种、颜色、大小比例、内外结构和包装继续以用户实拍为准。不要因外部案例更漂亮就改变品种、增加数量、加厚果肉、制造高等级状态，或照搬外部商品表面细节。

04、05 优先查看食品摆盘、商品静物和局部桌面布景，不把室内装修或生活空间效果图当作产品场景方案。用户提供案例时可直接提取可见关系；案例中的餐具只适用于允许器具的图号，不因参考有盘子或叉子就带入 02、03。

## 4. 抽取关系并重新设计

从可见画面提取主次、组合方式、前后、方向、视角、取景、裁切、留白和环境复杂度。只保留解决当前问题的关系，再映射到当前商品的真实形态和数量；不要复制某张作品的精确坐标、独特布景、道具组合或文字设计。

设计前以多张本品实拍确认主商品的完整形态和部件连接，再决定摄影关系。不能因某个局部适合构图就丢弃其余果身、果肉或连接；也不能把不同视角和展示状态中的局部拼接成实拍不存在的结构。外部构图关系必须能容纳完整的商品展示状态，不能迫使商品截短、消失或融合。

例如，从作品提取“前景切面说明内部、后景整件辅助识别、侧上方留白”，再根据当前商品的切法、厚度、重量和接触面决定摆放。外部图有三个商品，当前只允许两个时，重新组织两个的关系；不补第三个。作品中的餐盘关系不能搬入 03。

- **主次与大小：** 明确先看哪个主体。视觉大小可通过机位、距离和遮挡形成，不任意缩小切面、放大整果或改变同一水果的自然比例。不能规定每张都要大小悬殊或多个主体。
- **机位与景别：** 按信息选择平视、侧前方、轻俯或正俯。能在近景看清就不用极近景；不统一使用 45°、满画面圆果或强广角。01—03 先选商品关系再定景别，不能用怼近和原片裁切替代设计。
- **占比与留白：** 主体清楚，必要结构可读；满铺组合可以紧凑，留白不等于必须露出背景。03 可由周围商品铺至画面边缘，只要有效细节有明确主次、承托与自然个体差异。使用相对画面描述，确有需要才给本张估计比例；不设置通用 50%—70% 或其他固定阈值。
- **裁切与支撑：** 每次裁切有信息或方向上的理由。重要轮廓、果柄和包装信息不意外截断；切面、长条和堆叠物的重心、接触与承托可信。
- **03 美感细节：** 以果肉、切瓣、切面、厚薄或其他有效组织为主视觉，不选择果皮、果柄、果肩色带及表皮纹理主题。整体参照并非必需；原有切面边缘少量外皮可保留，不能转成整果表皮主视觉。其他食品按实拍选择叶层、组织、分层或工艺细节，不强制切开。
- **04、05 产品布景：** 从商品用途与使用阶段选择商品状态、摆盘、容器、承载面、少量必要道具和光线，默认在局部范围内完成画面。产品之间的主次、切面朝向和容器内排布先于环境设计，不用椅子、工作空间或房间布置交代生活感。室内外和时间可以通过局部材质及光线表达，不凭空暗示产地或采收状态。多产品批次对照已选摆盘、材质、器皿和机位，避免每个商品都套用相同组合；只有本图信息确实依赖更大空间时才扩大取景。

## 5. 确定唯一方案并接入 Prompt

发送前检查：本图信息明确、第一视觉锚点清楚、主次自然、尺度舒服、裁切有目的、承托可信，与整套信息互补。层次不是强制三层；对称、居中或平行本身也不等于失败，按当前商品和任务判断。

保存一份简短构图决策，字段可合并，不写与本图无关的内容：

```text
图号与本图信息：
商品形态、数量依据与展示状态：
选定主系统与选型依据（沿用原构图时注明）：
主视觉锚点与辅助元素：
前后、间距、朝向与视觉大小关系：
主体完整性、部件连接与遮挡延续：
实际接触与支撑：
拍摄角度与景别：
主体范围、裁切与留白：
背景或真实场景与光源：
与其他图的区别：
原始参考职责；外部灵感来源及提取的关系（未检索则注明）：
本次修整与关键失败约束：
```

对照多张实拍检查文字方案的数量、轮廓、朝向、主体完整性、部件连接、遮挡延续、主体尺度、留白与承托。方案与商品事实存在冲突时先修正方案，再写 Prompt；不增加程序绘图步骤，不让模型替规划阶段解决未确定的排布。Prompt 第一段说明每张实际输入的职责，第四段写入通用 Avoid 和本图结构风险。

将检查后的唯一方案接入主 Skill 的四段 Prompt：商品实拍依据 → 具体构图与动作 → 摄影和必要修整 → 关键失败约束与规格。不要发送整份决策表、系统库、多个选项，或只写“合理摆放”“选择好看的构图”。描述可执行的商品关系，保持语言简洁，避免把美感细节扩写成纹理、锐度或汁液强化。

生成前已作出的决定不等于模型一定执行。按[质检与返工](quality-and-retry.md)查看实际结果；构图满足任务且没有明显问题时通过，不为追求全字段完全一致而反复生成。
