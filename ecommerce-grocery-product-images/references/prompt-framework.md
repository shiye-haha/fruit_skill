# 最终图像生成提示词框架

最终发送给生图模型的 Prompt 统一写成 **4 个紧凑的自然语言段落**。不要发送 Skill 原文，不提供多个候选构图、场景或拍摄方案；Skill 内部先完成判断，Prompt 只保留已经选定的一套执行方案。

V1.1 的九项内容要求用于检查信息是否完整，不代表九段输出。将它们映射到四段格式：

| 四段 Prompt | 对应内容 |
| --- | --- |
| 第一段｜商品真实基准 | 商品事实、必须保持、允许美化 |
| 第二段｜本张图片拍摄方案 | 构图优化、背景与场景 |
| 第三段｜摄影质感与商业优化 | 摄影类型、光线、材质及本次具体修图 |
| 第四段｜真实性与失败约束 | 本次禁止项、输出规格 |

写作时每句话聚焦一个主要目标。若原图构图适合当前任务，就沿用并优化；若不适合，就明确选定新的整理方案，避免同一 Prompt 同时要求保留和重排同一摆放关系。

## 第一段｜商品真实基准

说明商品是什么、依据哪些实拍图，以及商品必须保留的核心特征和允许整理的原图问题。重点保持身份、形态、比例、结构、材质、颜色关系、实拍纹理和真实包装，不要求像素级复刻原图。

果蔬可写明仅减弱哪些小面积瑕疵，并可轻微改善水润、饱满或新鲜状态；包装需写明包装形态、材质、品牌和文字等必须保真，并只列本次允许整理的褶皱、塌陷、提手或反光等问题。

## 第二段｜本张图片拍摄方案

结合 [六图任务规范](six-image-plan.md) 和具体商品，写明本图要解决的消费者问题、展示信息与状态，以及确定后的商品摆放、主体位置和占比、角度、景别、完整或局部状态、前后关系、留白、背景、道具和场景。

不得保留候选项。不能写“可俯拍、侧拍或平视”，应由 Skill 选定最合适的一种并明确描述。切开、拆开或展示内部结构必须有实拍依据且适合当前商品。

## 第三段｜摄影质感与商业优化

明确摄影类型、光线、色彩、材质和本次允许的具体修图。01、02、03、06 通常使用专业商业商品摄影；04、05 使用真实生活场景商品摄影。建立一套能够解释整张图片的光照逻辑。按商品写出真实材质表现，并具体描述“修什么”，不使用笼统的“整体优化商品”。

## 第四段｜真实性与失败约束

只列本张最关键的错误约束，避免机械堆砌负向词。通常约束商品身份、数量、结构、比例、实拍质感、支撑与接触、透视、光影、1:1 单图输出。若画面包含果蔬切面、内部结构或包装文字，加入相应的专属约束；场景图则限制用途、道具和环境光影。

## 发送前检查

- 是否恰好四段自然语言，而不是把 Skill 或候选方案发送给模型？
- 每段是否只描述已选定方案，且商品事实和可修整内容有依据？
- 角度、场景、摄影棚或真实环境光是否已经明确，不互相冲突？
- 修图是否写成具体动作？失败约束是否针对本张图？
- 是否要求输出单张独立 1:1 图片？

## 示例｜白菜 01 主体图

以下示例只用于展示四段结构。实际任务必须替换成当前实拍支持的商品事实、图号任务和具体修整内容。

> 严格基于提供的大白菜真实实拍图。保持该白菜真实的品种特征、整体比例、菜帮与叶片结构、天然绿色层次以及真实叶片纹理，不重新生成另一种白菜外观。允许清理明显脏污、减弱少量影响展示的坏叶和表皮瑕疵，并轻微改善水润感与饱满程度，但继续保持天然、不完全均匀的真实蔬菜质感。
>
> 生成一张 1:1 产品主体图，让消费者第一眼清楚识别这是一颗大白菜。使用完整白菜作为绝对主体，将外层凌乱叶片自然整理，轻微调整商品朝向和画面位置，使整体轮廓舒展完整。采用自然三分之二侧前方视角和正常人眼观察距离，主体位于画面主要视觉区域并保留适量留白。使用简洁浅米灰摄影棚背景，不添加无关装饰和道具。
>
> 使用真实专业商业商品摄影。柔和主光从左前上方照射，使用轻微填充控制暗部，白菜与承载面之间存在自然接触阴影，高光保留叶片纹理不过曝。修正白平衡和曝光，保持自然绿色层次，轻微提升新鲜感、水润度和饱满度；减少少量影响商品展示的表面问题，但保持真实叶片、菜帮和天然纤维质感。
>
> 不得改变白菜品种、核心形态、菜帮比例、叶片结构或真实材质，不得增加或删除大量叶片。禁止塑料感、蜡质感、夸张水珠、人工 AI 纹理、过度饱和、过度磨皮、悬空、不合理接触、错误阴影和夸张透视。生成单张独立 1:1 商品摄影图，不生成拼图、文字、边框或水印。
