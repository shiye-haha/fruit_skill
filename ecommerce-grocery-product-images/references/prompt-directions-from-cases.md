# 果蔬商品图提示词方向参考

来源：用户提供的柚子、凤梨商品图案例提示词。此文件是案例经验整理，**仅供按需参考，不增加硬性规则，也不覆盖本 Skill 或用户本次要求**。使用时先确定当前商品、图号、用户指定的编辑范围，再挑选适合的方向。

## 可借鉴的方向

### 1. 把不同参考图的职责说清楚

案例中常把商品事实图与构图参考分开：一张约束整果轮廓、颜色和姿态，另一张约束切面、果肉和白瓤；另有图片只用于观察排列、景别或空间关系。这个做法有助于减少参考冲突。每张参考图只承担当前任务真正需要的职责，不要把风格图的商品颜色、背景或道具误当成商品事实。

### 2. 让每张图只解决一个购买问题

柚子案例展示了几种可选表达：完整果与切面组合、果肉瓣近景、半果切面、剥好待食或场景应用。凤梨案例展示了切片、装盘和局部新鲜感修整。可借鉴的是“先选这张图要让顾客看懂什么”，再选角度与景别；这些案例不是固定的六图模板。

### 3. 用前后层次和景深建立主体关系

前景切面或果肉、后景整果轻微虚化，是一种清楚表达“内部状态来自这种商品”的方式。近景要保留足够形状线索，避免只剩抽象纹理；背景辅助物体只在确有信息价值时出现，虚化程度服务于主体辨识。

### 4. 让商品状态与场景用途相符

案例中的场景包括剥好待食、餐桌分享、厨房或阅读时光等。可借鉴生活情境与商品状态之间的联系，例如整瓣适合“刚剥好分享”，小块适合“准备取食”。道具应少而有用，环境需要有真实空间和一致的光照逻辑。

### 5. 用具体摄影语言表达质感

较有效的方向包括：有方向的柔光塑造体积，适度补光保留暗部；让果肉有轻微自然湿润感，同时保留纤维、汁胞和断面；用背景虚化与接触阴影建立空间；校正明显色偏和曝光。修整描述应对应可见问题，例如“降低切面硬亮反光”“清理盘沿孤立碎屑”，比泛泛写“高级、真实、诱人”更可执行。

### 6. 明确“保持什么”和“只改什么”

凤梨案例中的“构图不变，只改善新鲜感”展示了窄范围编辑的写法。可迁移为：指定保留商品与构图，明确本次仅调整的背景、曝光或局部问题，并要求其他已认可内容保持。工具不支持像素级锁定时，要把它视为编辑目标，生成后检查实际变化。

## 案例中的高风险写法

以下内容在原表中多次出现，但应视为某张图的个案选择，不能直接复制成通用硬规则：

- 固定左右位置、精确果肉瓣数、精确占比和道具角落位置。它们可能使构图僵化，也可能改变实拍的商品数量或形态。
- 要求果肉颜色“完全统一”、切面更开阔、中心组织更紧、果肉更饱满或更透亮。过度执行会抹掉自然差异，放大胶质高光，甚至虚构内部组织。
- 很长的“避免出现”清单、同义形容词反复堆叠。负向词太多会稀释画面目标，还可能让模型反复关注原本不想强调的缺点。
- 一条提示词同时重排商品、换背景、换光线、修纹理、加道具和改变色彩。若结果不理想，难以判断是哪项造成的变化；返工时应聚焦当前问题。
- “白底/不要白底”“带叶/不带叶”“盘子/玻璃碗”等互斥选择。它们必须按当前图号和素材择一，不能把多个案例拼成一条提示词。
- 将“水润、饱满、真实”直接翻译成大量镜面高光、透明发光或完美统一果粒。这些词应由真实材质和光源支撑，避免塑料、果冻或CG观感。

## 与现有 skill 的关系

本参考文档不覆盖 skill 的执行顺序和验收标准。实际工作仍按 skill 执行：商品身份、实拍质感和核心特征优先；01–06 各自解决不同信息任务；04/05 使用真实场景逻辑；包装文字与身份信息保真；最终提示词保持四个紧凑自然语言段落。

表格案例中“高端广告感、固定色盘、完全统一颜色、指定数量与布局”等表达，只有在符合当前素材和用户目标时才采用。它们不能取代 skill 对商品真实结构、必要修整边界、真实场景光线和包装保真的要求。若商品已由用户确认，只修改用户指出的部分。

## 使用前快速筛选

1. 这段案例是在讲商品事实、构图、场景还是局部编辑？
2. 当前参考图是否真的支持这项商品事实？
3. 其中的数量、颜色、位置和道具是当前任务要求，还是仅为案例选择？
4. 是否会改变商品本身，超出本次允许的编辑范围？
5. 能否把所选方向压缩进 skill 要求的四段提示词，并只保留当前必要的约束？
