# 电商果蔬食品商品图

根据用户提供的真实商品实拍，规划并生成六张独立的 1:1 电商商品图。目标是通过专业摄影级整理和适度优化呈现真实商品，保持商品身份、核心结构、材质、颜色和实拍质感。

## 执行原则

1. 先查看多张本品实拍，交叉确认商品整体形态、连接、材质状态与细节可见程度、可修整问题，以及当前图片属于常规商品图还是场景图。每张生图实际上传至少两张互补的本品实拍，明确主参考与各图职责；不能只上传一张，也不能用重复照片或外部案例凑数。素材不足时说明缺口，不虚构参考。区分正常天然特征、明显残缺或损伤，以及水痕、反光、噪点等拍摄因素；逐处记录需要修整的位置，不能把损伤笼统归入“真实纹理”。不能从模糊或过曝区域推测精细结构。
2. 按优先级处理：商品身份正确 > 实拍级真实感 > 核心特征保持 > 必要美化 > 摄影表现 > 美观。真实性与美观冲突时保留真实性。
3. 根据 [六图任务规范](references/six-image-plan.md) 确定每张图的购买问题、商品状态与参考图职责。整套任务先横向检查六张的功能，单张任务检查当前图与已有图片的关系。
4. 写 Prompt 前读取 [真实性与修整边界](references/product-fidelity-and-retouch.md) 和 [摄影与构图规则](references/composition-lighting.md)。选择商品静物重组、局部产品布景或保真整理，限定本次需要改变的内容。实拍提供商品事实；新套图的 01—03 须判断组合、角度和留白是否有设计，只裁切或放大原片不能代替构图。用户已认可构图的局部修整沿用原有关系。
5. 执行 [前置构图决策](references/composition-planner.md)：判断商品形态和本图信息 → 筛选内部构图系统 → 没有合适方案时检索 ZCOOL / VCG / 58pic → 提取摄影关系 → 按当前商品重新设计 → 确定唯一文字方案 → 写 Prompt。规划 03 时读取[03 布局参考](references/composition-03-layouts.md)，查看适合当前商品的示例。记录选型依据，检查支撑、留白和整套差异；不增加程序绘图步骤。已认可构图的局部返工沿用现有方案，不强制重排。
6. 需要借鉴柚子、凤梨等既有案例的画面表达时，可选读[案例提示词方向参考](references/prompt-directions-from-cases.md)。它只提供案例灵感，不增加硬性规则，也不覆盖本 Skill 或用户本次要求。
7. 最终 Prompt 使用四个紧凑自然语言段落：商品真实基准与参考职责、唯一构图和本张拍摄或编辑方案、必要的摄影与修整、Avoid 与输出规格。第四段使用[通用 Avoid](references/prompt-avoid.md)，再补本图关键失败约束；保留主体完整和结构连续的约束。将数量、主次、前后、朝向、机位和留白等决定转为具体摄影语言，不让生图模型自行选构图。只发送确定方案，不附候选方案或 Skill 原文；不为补满段落堆叠形容词。
8. 按 [质检与返工规则](references/quality-and-retry.md) 查看单图及整套结果。发现明确不合格时自动根据失败项调整参考、方案或 Prompt 并重新生成，合格即停止；单张最多生成五次，包含首版与返工，不因换参考或换方案重置次数。生成时保存文字构图决策、实际发送的 Prompt、按顺序排列的参考输入与输出对应关系；外部灵感与实际上传图片分开记录。整理版提示词须另外标明，不能冒充真实调用记录。
9. 按用户当前请求交付方案、Prompt 或图片。用户已认可的风格与修整幅度作为当前批次基准；后续集中处理明确的问题。只有用户要求整套六图时才连续处理后续图，单张任务完成后停止。

## 固定要求

- 输出单张、独立的 1:1 图；六张图不能拼成一张图。
- 商品数量、品种、包装身份和实拍支持的特征不得擅自改变。
- 构图设计通过多张本品实拍提取需要的形态、结构、颜色和材质特征，再调整摄影关系；不能借重排之名完全重塑商品。所选展示状态下的主体必须完整、连续，不能让果肉、果身或连接部位无故消失、截短、融合或错接。合理遮挡须由实际前后关系解释，不能用遮挡为结构缺失辩解。
- 01—03 按本图信息设计商品静物：选择组合、切法、前后、朝向、机位和留白，不默认单个主体贴满画面或将同一原片连续裁切成三图。已有构图确实适合或已获认可时保留有效关系，同时保持商品身份、数量和真实形态。
- 01、02、03、06 默认采用简洁商业摄影棚逻辑；04、05 默认采用聚焦商品的局部产品场景与布景，通过容器、承载面、摆放和少量必要道具表达用途。环境范围服务商品，不为交代生活情境扩大到房间、椅子或工作空间。场景光和摄影棚布光不可混用。
- 02、03 聚焦商品本体，不加入砧板、餐具等生活工具。02 按实际商品选择核心品质细节；03 展示与 02 互补且更具美感的果肉、切面、切瓣、厚度或其他有效结构，不以果皮、果柄、果肩色带或表皮纹理特写作为主题。03 可选择商品铺满画面，以清楚的切开、剥好或其他有效细节为视觉主体，周围同商品形成陪衬；不强制留出大片背景。具体边界见六图任务规范。
- 04、05 按质检规则检查光线、比例、支撑、透视与使用阶段；以可见的明显矛盾判定返工，不把证据不足的猜测或轻微摆拍感当作逻辑错误。
- 每张图的提示词写明经观察确认的修整位置与动作，以及本图最关键的失败约束。以正常展示尺度判断，只自然修整突出的较大残缺、擦伤、破口或伤斑；小斑点、轻微擦痕、自然色差和正常切口保留。较大缺陷无法在保留商品身份和数量的前提下修好时，换用更完整的参考图或合适角度。具体边界见真实性与修整规则。
- 清楚的轮廓、结构与文字应保留；微纹理的尺度、强度和密度以同等观察尺度下的实拍为准。光滑、粗糙、干燥或湿润按具体商品判断，不统一加强纹理，也不统一磨平。
- 形态参照须落实到实拍中的可见轮廓、长宽关系、自然曲率、棱面和连接部位，不仅用“短胖”“饱满”等概括词让模型重塑商品。有本品对应材质实拍时，外部案例只提供构图、切法或摄影方向，不主导表皮、果肉和内部组织的质感。
